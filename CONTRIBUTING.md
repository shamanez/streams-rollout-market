# Contributing

The project is intentionally contract-first. Good first contributions include:

- Improve schema validation and error messages.
- Add adapters for rollout engines or trainer frameworks.
- Add benchmark tasks and synthetic long-horizon traces.
- Implement verifier plugins.
- Add OPBC metrics and controller policies.
- Write documentation for tool-output masks and policy pinning.

Before opening a large PR, create an issue that states the contract surface it changes.
